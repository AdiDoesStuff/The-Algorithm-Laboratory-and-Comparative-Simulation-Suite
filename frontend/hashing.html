Algorithm Laboratory: Hashing

How hashing works here

A hash function maps a key to an array index. This lab uses two hash functions: sum_mod (sum of character codes modulo table size) and poly_mod (a polynomial rolling hash with base 31, modulo table size). Collisions are handled by separate chaining (linked lists per bucket) or open addressing (linear probing with tombstones on delete). Tables resize (rehash) when the load factor exceeds the threshold. Different functions distribute keys differently; sum_mod collides on anagrams.

Keys are case-sensitive; spaces are not allowed. Enter inserts.
