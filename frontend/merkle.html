Algorithm Laboratory: Merkle Trees

What is a Merkle tree?

A Merkle tree is a binary tree of hashes. Each leaf is the hash of a data block (here, SHA-256 of the block text). Each internal node is the hash of its two children's hashes concatenated. The single hash at the top is the Merkle root, which commits to the entire set of blocks: change one block and only the hashes on the path from that leaf to the root change. This lets a verifier check a single block against the trusted root using only O(log n) sibling hashes. Odd levels duplicate the last node so every level pairs up.

Build the tree

Build hashes every block, then pairs hashes bottom-up until one Merkle root remains.

Blocks

1–16 blocks, 0–40 characters each. Empty blocks are allowed.
